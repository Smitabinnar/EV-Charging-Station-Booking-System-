# EV Charging Station Booking & Management System

## Project Description

The EV Charging Station Booking & Management System is a web application that allows electric vehicle users to find charging stations, check charger availability, book charging slots, and make payments online. It also provides an admin panel to manage users, stations, chargers, bookings, and payments.

---

## Modules

### User Module
- User Registration
- User Login
- User Profile Management

### Vehicle Module
- Add Vehicle
- Edit Vehicle
- Delete Vehicle

### Charging Station Module
- View Charging Stations
- Search Charging Stations
- View Charger Availability

### Booking Module
- Book Charging Slot
- Cancel Booking
- View Booking History

### Payment Module
- Make Payment
- View Payment History

### Admin Module
- Manage Users
- Manage Charging Stations
- Manage Chargers
- Manage Bookings
- View Payments
